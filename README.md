## Key Features

- **Recursive Sitemap Crawler**: Automatically discovers, expands, and validates all URLs declared in `sitemap.xml` and sitemap index files.
- **HTTP Status & Canonical Audit**: Checks response status codes (200, 301, 302, 404), detects redirect chains, and verifies matching `<link rel="canonical">` tags.
- **Social & Meta Tag Extraction**: Audits `<title>`, `<meta name="description">`, Open Graph (`og:title`, `og:image`, `og:url`), and Twitter Cards.
- **Schema.org JSON-LD Verification**: Validates structured data blocks for Google Rich Results compatibility.
- **Turnkey Apify Integration**: Run on demand or schedule automated runs on [Apify Console](https://apify.com/b2apps/public-sitemap-seo-auditor).
